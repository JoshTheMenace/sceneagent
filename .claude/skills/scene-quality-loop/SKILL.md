# Scene quality loop (adapter)

The canonical skill lives at `skills/scene-quality-loop/SKILL.md` in this
repository. Read that file now and follow it exactly — its `references/`
(polish-protocol, spatial-contracts), `scripts/` (validate_polish.py), and
`assets/` templates all resolve relative to that directory.

Key rule: declarations such as `grounded: true` are not evidence — require a
measured `spatial-report.json` before visual scoring, and never let the
builder score its own work (builder self-scores run ~0.2 high versus
independent review).
